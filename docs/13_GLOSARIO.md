# 13 · Glosario claro

| Término | Significado |
|---|---|
| Quiniela | Juego sobre 14 signos 1/X/2 y el resultado del Pleno al 15 según reglas vigentes |
| Jornada | Conjunto de partidos correspondiente a una fecha/sorteo |
| Signo 1 | Victoria del primer equipo |
| Signo X | Empate |
| Signo 2 | Victoria del segundo equipo |
| Fijo | Se elige una sola opción en ese partido |
| Doble | Se eligen dos opciones en ese partido |
| Triple | Se eligen las tres opciones 1/X/2 |
| Columna | Una apuesta concreta con un signo en cada uno de los 14 partidos y marcador del Pleno |
| Pleno al 15 | Predicción de goles local/visitante en el último partido; `M` representa 3 o más |
| Sistema | Conjunto o fórmula que produce varias columnas |
| Reducción | Elegir un subconjunto de apuestas para bajar coste controlando cobertura |
| Reductor | Algoritmo que selecciona ese subconjunto |
| Garantía | Afirmación matemática verificada sobre un universo de resultados declarado |
| Cobertura | Fracción de resultados del universo para la que el sistema consigue un nivel de acierto |
| Universo Ω | Conjunto de resultados hipotéticos evaluados; afecta todas las garantías |
| Columna Base (CB) | Columna o máscara de signos de referencia contra la que se comparan otras |
| Reserva | Condición con tolerancia permitida, no obligatoria en todos los casos |
| Distancia de Hamming | Número de posiciones en las que dos columnas de 14 signos difieren |
| Filtro | Regla para aceptar o eliminar columnas |
| Escrutinio | Comprobación de aciertos a partir de los resultados de la jornada |
| Simulación | Cálculo de escenarios hipotéticos, no resultado futuro cierto |
| Probabilidad deportiva | Estimación de posibilidad de que ocurra un resultado |
| Porcentaje jugado | Frecuencia con la que los participantes eligen un signo |
| Recaudación | Dinero total ingresado en una modalidad/jornada |
| Acertantes | Número oficial o estimado de apuestas que aciertan una categoría |
| Premio estimado | Aproximación no oficial cuyo importe puede cambiar |
| Premio oficial | Cuantía publicada y confirmada por organismo competente |
| Valor esperado (EV) | Promedio probabilístico del premio menos coste en un modelo dado; no garantía |
| ROI | Resultado neto dividido por coste apostado; se calcula solo si el coste es positivo |
| Backtesting | Evaluación de estrategia con jornadas pasadas respetando la información disponible en aquella fecha |
| Fuga temporal de datos | Error de utilizar información futura para predecir resultados del pasado |
| Calibración | Comprobación de si probabilidades declaradas coinciden con frecuencias observadas |
| Brier score | Métrica de error de probabilidad: menor valor suele ser mejor |
| Log loss | Métrica que penaliza especialmente probabilidades muy seguras pero equivocadas |
| Iterador perezoso | Genera columnas conforme se necesitan, sin almacenar todas en RAM |
| Fixture | Datos de prueba conocidos y repetibles |
| ADR | Registro de una decisión de diseño y sus consecuencias |
| Adapter | Componente que conecta una fuente/formato externo con el modelo interno |
| ASD | Formato de soporte digital de apuestas; el nombre no basta para conocer su especificación |
| QR oficial | Código de validación sometido a especificaciones y controles externos; distinto del QR interno |
| Local-first | La funcionalidad fundamental funciona con archivos locales, sin depender de servicios externos |
